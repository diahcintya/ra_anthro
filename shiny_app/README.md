# Child Anthropometry Dashboard

Interactive Shiny app for the anthropometric outcomes built by this
project's pipeline. Pick a country from the dropdown or click a marker on
the map — both drive the same selection, updating the stunting/wasting/
underweight/overweight rates and mean z-scores shown below.

## Data

`country_summary.csv` is a small, **country-level aggregated** table (14
rows: `n_children`, mean `haz`/`waz`/`whz`, and outcome prevalence rates
per country), generated by `prepare_data.R` from
`harmonized_outcomes/anthro_merge.rds`. No individual child records are
included — see the root `.gitignore` and `ANTHRO_EXTENSION_PLAN.md` for why
the underlying survey microdata isn't published.

Country coordinates in `country_summary.csv` are capital-city centroids
(for map placement only, not derived from the survey data — no lat/long
field exists in the harmonized dataset).

## Run

```r
shiny::runApp("shiny_app")
```

To regenerate `country_summary.csv` from a fresh pipeline run (requires
the full, locally-built `harmonized_outcomes/anthro_merge.rds`, not
included in this repo):

```r
# from the repo root
source("shiny_app/prepare_data.R")
```
